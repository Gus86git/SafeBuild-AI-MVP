# Derechos y atribuciones

## Código del proyecto

No se encontró una licencia de proyecto explícita en el conjunto de archivos de origen revisado. No se asignó una licencia automáticamente. ## Recursos visuales

`assets/safebuild/hero-conceptual.png` y `dashboard-reference.png` son recursos aportados para la interfaz. El responsable del proyecto declaró el 10 de noviembre de 2026 que tiene permiso para incluir ambos en el nuevo repositorio privado. Esta declaración no acredita por sí sola autorización para redistribución pública posterior. La imagen conceptual no representa una inferencia real.

Los iconos vectoriales y el CSS existentes se conservan. No se eliminaron atribuciones o avisos de licencia encontrados en los archivos seleccionados.

## Recursos separados

Pesos YOLO, embeddings, documentos, índices y medios de prueba no están incluidos. Para incorporarlos: comprobar procedencia, licencia, privacidad, restricciones de distribución y hashes. La autorización local de ejecutar un peso no equivale a permiso de redistribuirlo.

## Dependencias

Cada dependencia conserva sus condiciones. Revisar particularmente los requisitos de distribución/uso de Ultralytics, PyTorch, modelos Hugging Face, ChromaDB y los servicios externos antes de elegir una licencia del producto. No se afirma compatibilidad jurídica de todo el conjunto sin revisión.

La trazabilidad histórica y académica completa se conserva en el archivo local de preparación y en el proyecto original. Si una institución exige declarar herramientas o procesos de elaboración, mantener esa declaración en la documentación académica que corresponda; esta presentación del producto no la reemplaza.
